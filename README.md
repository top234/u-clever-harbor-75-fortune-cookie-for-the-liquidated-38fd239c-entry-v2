# Fortune Cookie for the Liquidated Trader — v2

One fortune cookie line for a crypto trader who has just been liquidated.
This is the v2 entry: shorter and sharper than v1, with the cookie itself
sharing the trader's loss — the fortune inside was liquidated before the
cookie was even opened.

> This cookie is empty, trader — your fortune was liquidated before you opened it.

## Run

```sh
node main.ts
```

It writes one line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
Node 22 or later. No dependencies, no network, no secrets.
